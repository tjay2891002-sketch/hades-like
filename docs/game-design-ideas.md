# Hades-like · 设计灵感库

> 本文档汇总当前《Hades-like》可扩展的设计方向，供后续迭代时参考。
> 现有系统基准：5 座单神神像 + 5 把可解锁武器（开局选定、战斗中不可换）、
> 清场后选择出口门进入下一关、局外碎片解锁永久加成、敌人类型含追击/冲锋/射手/坦克与精英。

---

## 一、武器与打法

### 1. 武器形态（Aspects）
- 每把武器提供 2~3 种“形态”，用局外碎片/材料永久解锁。
- 形态不改变武器外观归属，而是改写普攻节奏或机制，例如：
  - **短剑**：标准连击 → “影刃形态”位移突刺，攻击后短距离后撤，鼓励贴脸拉扯。
  - **长弓**：蓄力狙击 → “猎风形态”三连散射，牺牲单发伤害换覆盖面。
  - **大剑**：重击 → “磐岩形态”蓄力期间获得霸体，蓄满后范围劈砍。
- 目标：让每把武器都有“该玩哪套手感”的记忆点，而不是单纯数值化。

### 2. 武器专属“架势 / 资源”
- 给每把武器一个独立小资源，命中积攒、消耗触发强化，例如：
  - 长枪“枪势”：命中回复，集满下次突刺伤害翻倍并贯穿。
  - 大剑“怒气”：受击或重击积攒，消耗进入短暂攻击强化。
- 与祝福体系分层：祝福改“通用词条”，架势改“武器个性”。

### 3. 武器变体祝福
- 按当前武器形态动态生成可选项，让“这把枪这次能变成什么样”成为路线乐趣。

## 二、神明与赐福

### 1. 稀有度阶梯
- 普通 / 稀有 / 史诗 / 传奇四档，越稀有词条越强、触发更苛刻。
- 同神卡池内集齐特定组合解锁“传奇”，给玩家明确的构筑目标。

### 2. 双神联动（Synergy）
- 两神的特定祝福并存时出现“联动祝福”，例如：
  - 宙斯（雷）+ 波塞冬（海）= “风暴”：雷击附带溅射。
  - 阿瑞斯（战）+ 赫尔墨斯（速）= “疾风”：暴击后加移速，撞出额外伤害。
- 让“选神路线”不再是单神堆叠，而是跨神构建。

### 3. 诅咒 / 高风险祝福
- 增强但附代价，例如：
  - “血怒”：伤害 +50%，但受到的伤害也 +30%（可配吸血构筑）。
  - “玻璃大炮”：攻击大幅提升，但最大生命 -30%。
- 给高玩一条“用操作换数值”的选择。

### 4. 祝福升级 / 融合
- 已选祝福可花金币/碎片升级；同名祝福可“融合”成更高稀有度卡。
- 解决“中期拿到鸡肋祝福”的挫败感。

## 三、敌人与 Boss

### 1. 精英词缀
- 同一基础怪挂不同词缀，反复遇也不腻：
  - **狂暴**：低血量加速、攻击更凶。
  - **护盾**：破盾后才吃伤害，逼你换输出节奏。
  - **分身**：死亡分裂小怪。
  - **自爆**：死亡后留范围爆炸区，逼走位。
- 词缀按房号/难度逐步进入，控制强度曲线。

### 2. Boss 多阶段 / 机制
- 避免“血牛站桩”，加入阶段转换：
  - 阶段一近战，阶段二召唤小怪 + 环状弹幕。
  - 护盾阶段：需先清小怪或打断，打破“无脑贴脸”打法。
- 给每关 Boss 一个“记忆点机制”，而不是只有数值。

### 3. 敌人协同组合
- 射手远程压制 + 坦克前排牵制，形成“必须切后排”的组合。
- 设计 1~2 种“组合技”：如射手被坦克举盾时进入无敌，需先处理坦克。

## 四、房间与路线

### 1. 事件房
- 随机事件增加“选择感”：
  - **血祭**：献祭当前血量上限，换取一件强力祝福。
  - **赌博**：金币押注，成败随机。
  - **谜题挑战**：限时/规则击杀，奖励碎片或稀有祝福。
- 与现出口门徽章联动：事件房作为可选支线而非必经之路。

### 2. 特殊房
- **试炼房**：连续波次生存，层数越高奖励越好。
- **混沌房（规则反转）**：本房内元素/祝福规则临时改变。
- **隐藏房**：达成特定条件才开（如本局未受伤、击杀数达标）。

### 3. 徽章选门深化
- 现有出口徽章显示类型/敌人数，可再加：
  - 用颜色/图标区分“战斗 / 精英 / 事件 / 商人 / Boss”。
  - 显示“本门奖励倾向”，让选门更有策略。

---

## 五、局外成长（Meta）

### 1. 信物 / 纪念品
- 开局可携带一件，影响初始构筑，例如：
  - 加初始生命、加初始金币、首层祝福保底某神。
- 给局外一个“这把想玩什么流派”的开关。

### 2. 预言 / 挑战系统
- 完成特定条件解锁新内容（新神、新武器形态、新敌人），形成长期目标清单。

### 3. 神殿装饰
- 用碎片购买装饰 + 微小加成，纯“养成家园”的正反馈。

---

## 六、手感与表现（Juice）

- **处决 / 终结技**：精英或 Boss 残血时可触发处决，增加爽感。
- **连击 / Combo**：连续命中积攒连击数，接奖励效果。
- **翻滚无敌帧奖励**：滚过攻击瞬间触发短暂强化，鼓励“打铁式”闪避。
- **Hitstop 顿帧**：命中瞬间短暂停顿，强化打击反馈。
- **受击震屏 / 音效**：已有基础，可再按命中轻重分级。

---

## 七、叙事 / 主题（可选）

- 为每位神明设计一条简短背景线，随局外进度逐层解锁，形成“为何在此战斗”的动机。
- 多周目结局：通关后开放新难度选项，或揭示更大真相。
- 给“神像”——神与玩家关系——做最小叙事钩子，避免纯刷。

---

## 八、落地优先级建议

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| P0 | 稀有度阶梯 + 双神联动 | 直接改变构筑乐趣，成本低 |
| P0 | 精英词缀 | 用现有敌人快速增加新鲜感 |
| P1 | 武器形态 / 架势 | 武器辨识度核心，工作量较大 |
| P1 | 事件房 / 特殊房 | 增强路线选择，中期内容 |
| P2 | 手感 Juice（处决 / hitstop） | 低成本高感知 |
| P2 | 叙事 / 多周目 | 内容丰富度兜底 |

> 建议先做 P0（稀有度 + 双神联动 + 精英词缀），用最少改动验证“构筑乐趣”，再逐步向 P1/P2 扩展。
